🚫 Do not use AI background removal

💡 You are lighting a real 🟢 green screen. 🤖 AI segmentation often leaves soft edges and flicker around hair. 📷 Use the camera’s clean HDMI plus OBS’s hardware-friendly Chroma Key filter instead. ⚡ The result is a finished composite in the recording — 🚫 no second render pass.

🔗 Signal chain

📷 Sony ZV-1✨ Clean HDMI, Rec.709, locked exposure
➡️
🔌 Cam Link 4K💻 Uncompressed capture into the Mac Mini
➡️
🟢 OBS Chroma Key✂️ Green key + spill reduction
➡️
⏺️ Record🗣️ Talking head already composited

  1. 1 📷 Lock the Sony ZV-1

    ⚠️ Auto camera settings will drift the green, and the key will break mid-take. 🧊 Freeze everything.

    🎛️ Control📌 Set to💡 Why
    🎚️ ModeMStops auto exposure from shifting the key
    ⏱️ Shutter1/125s @ 60fpsMatches frame rate without flicker
    📡 ISO400–800Clean enough, still bright on the subject
    ☀️ WBDaylight / 5600KGreen stays the same green all take
    🎨 Picture ProfileOffRec.709, not a log/flat look that weakens the key

  2. 2 🟢 Configure Chroma Key in OBS

    🧪 Filter📌 Starting value🛑 Stop when
    🟢 Key Color TypeGreen—
    🎚️ Similarity300–400Backdrop is black; fabric is still solid
    ✂️ Smoothness10–80Edges stay sharp

  3. 3 ✨ Fix green spill (especially on Mac)

    💚 Green light bounces onto hair, shoulders, and skin. 🧹 Kill that bounce in the filter stack, not in a later grade.

    📚 Filter order

    1️⃣ Chroma Key
    2️⃣ Color Correction

    ⬇️ OBS applies effect filters top to bottom. Color Correction must sit under the key.

    ✅ What “done” looks like

    💇 No lime outline on hair. 🧑 Skin is not mint. 👕 Shirt opacity is 100%. 🖼️ Background is the image or loop — not green, not a hole.

  4. 4 🎬 Layer the scene and record

    📚 Sources window, top to bottom:

    ⬆️ Top — 📷 Sony ZV-1 (🔌 Cam Link 4K) with 🟢 Chroma Key applied
    ⬇️ Bottom — 🖼️ Replacement background (image, video loop, or Display Capture)
    ⬆️ [ Top Source ]    → 📷 Sony ZV-1 (🔌 Cam Link 4K + 🟢 Chroma Key)
⬇️ [ Bottom Source ] → 🖼️ Replacement background (image / loop / display)

    ✅ Verify with a 15-second clip

    🖼️ Put the new background behind you, hit ⏺️ Start Recording, talk for 15 seconds, stop. ▶️ Play the file in QuickTime. If edges are sharp and skin has no green tint, the setup is finished. ⚡ From here every video can be produced in OBS with no second render.

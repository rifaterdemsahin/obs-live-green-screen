💬 Implementing Captions

Captions make your content accessible and engaging. Here is how to add them to your live recordings and fast production workflow! 🎙️

🚀 Option 1: AI Auto-Captions directly on Screen (Local & Free)

This method generates real-time speech-to-text directly inside OBS using your GPU/CPU without needing external websites.

  1. Create the Text Output Source:
    • In OBS, go to your Sources dock and click + > Text (GDI+) (or Text (FreeType 2) on Mac).
    • Name it Live Captions and click OK.
    • Choose your desired font, size, and styling (e.g., Bold, white text with a black outline for contrast). Click OK.
  2. Install the LocalVocal Plugin:
    • Download the LocalVocal installer from the official OBS Studio Forum or GitHub repository.
    • Run the installer while OBS Studio is closed.
    • Relaunch OBS.
  3. Apply the Caption Filter to Your Microphone:
    • In the Audio Mixer panel, find your Microphone source, click the three dots / Gear icon, and select Filters.
    • Click + under Audio Filters and select LocalVocal.
    • Under the Output Source dropdown in the filter settings, select the Live Captions text source created in Step 1.
    • Enable Partial Transcriptions so words appear letter-by-letter as spoken.
  4. Add Motion / Animation FX:
    • Right-click your Live Captions text source in the Sources panel and select Filters.
    • Click + under Effect Filters and add Move / Transition FX (if using the OBS Move Transition plugin) or standard motion filters to make the text bounce, fade, or slide into frame upon updating.

Verification: Speak into your microphone while watching the OBS Preview window—text should pop up letter-by-letter over your webcam layout.

✂️ Option 2: Animated Browser Source Captions (Custom CSS / FX)

If a dynamic, stylized visual overlay (similar to TikTok/Instagram Reels animated captions) is preferred, use an auto-captioning web app loaded into a Browser Source.

  1. Generate the Caption Link:
    • Use a real-time web captioning platform like WebCaptioner or VDO.Ninja Captioning.
    • Set up your microphone source on the web interface.
    • Copy the widget / output URL generated by the platform.
  2. Add to OBS as a Browser Source:
    • In OBS, click + in the Sources panel and choose Browser.
    • Paste the URL into the URL box.
    • Set the dimensions (e.g., Width 1920, Height 1080 or 1080x1920 for vertical content).
  3. Inject Custom Animation CSS:
    • In the Browser Source properties, scroll down to the Custom CSS field.
    • Paste keyframe animations to give words a pop-up effect when they render:
    body { background-color: rgba(0, 0, 0, 0); overflow: hidden; }
span {
  display: inline-block;
  animation: popIn 0.15s ease-out;
}
@keyframes popIn {
  0% { transform: scale(0.8); opacity: 0; }
  100% { transform: scale(1); opacity: 1; }
}

Verification: Speak into your mic; captions should pop onto the screen with a scaling entrance effect.

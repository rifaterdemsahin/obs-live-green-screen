🎨 VDO.Ninja Animated Captions CSS

To create animated captions using Caption.Ninja, you capture transcription data via speech-to-text parameters, send it to a browser overlay, and style the elements with Custom CSS inside OBS.

⚠️ Text Wrapping & Overlapping Fix

Caption.Ninja creates multiple overlapping HTML div blocks for interim and final transcriptions. Combined with position: absolute and custom animations, this causes old text containers to stack on top of each other indefinitely.

To resolve the overlapping text and force old captions to automatically disappear after a few seconds, follow the updated steps below.

Step 1: Update the OBS Custom CSS

Double-click your Browser Source in OBS, clear out the Custom CSS field entirely, and paste this updated stylesheet:

/* 1. Reset container flow to prevent static position stacking */
html, body {
  background-color: transparent !important;
  background: none !important;
  margin: 0 auto !important;
  padding: 0 !important;
  width: 100% !important;
  height: 100% !important;
  overflow: hidden !important;
}

/* 2. Position the main caption container at bottom center */
#output, #overlayMsgs, body > div {
  position: absolute !important;
  bottom: 80px !important;
  left: 5% !important;
  width: 90% !important;
  text-align: center !important;
  margin: 0 auto !important;
  white-space: normal !important;
  word-wrap: break-word !important;
}

/* 3. Hide old duplicate/interim containers to stop overlapping text */
#output > div:not(:last-child),
#overlayMsgs > div:not(:last-child) {
  display: none !important;
}

/* 4. Base text style: Red with White Border */
* {
  color: #FF0000 !important;
  font-family: 'Montserrat', 'Arial Black', sans-serif !important;
  font-weight: 900 !important;
  font-size: 48px !important;
  line-height: 1.3 !important;
  text-transform: uppercase !important;
  text-shadow: 
    -3px -3px 0 #FFFFFF,  
     3px -3px 0 #FFFFFF,
    -3px  3px 0 #FFFFFF,
     3px  3px 0 #FFFFFF,
    -4px  0px 0 #FFFFFF,
     4px  0px 0 #FFFFFF,
     0px -4px 0 #FFFFFF,
     0px  4px 0 #FFFFFF !important;
}

/* 5. Clean pop-in without animation freeze */
span {
  display: inline !important;
}

Step 2: Update the URL Parameters to Auto-Clear Old Text

Caption.Ninja has built-in parameters to automatically clear old captions after a set period of silence and force single-buffer text output so overlapping is impossible.

Update your Browser Source URL in OBS to this exact link:

https://caption.ninja/overlay?room=qpxsL6y9Ho9SPCo0&maxlines=2&clear=3&timeout=3&interimmaxlines=2&maxwords=6

What these parameters fix:

  • &clear=3: Clears the caption text automatically after 3 seconds of silence.
  • &timeout=3: Forces old transcriptions to expire so they don't linger indefinitely on screen.
  • #output > div:not(:last-child) { display: none !important; } in the CSS: Hides previous sentence containers so new text never overlaps on top of old text.

Step 3: Refresh the Source

  1. Scroll down to the bottom of the Browser Source properties in OBS.
  2. Click Refresh cache of current page.
  3. Click OK.

Verification: Speak into your mic. The text will show up cleanly without stacking on top of old lines, and once you stop speaking, the text will vanish completely after 3 seconds.

🎨 VDO.Ninja Animated Captions CSS

To create animated captions using Caption.Ninja, you capture transcription data via speech-to-text parameters, send it to a browser overlay, and style the elements with Custom CSS inside OBS.

⚠️ Text Wrapping Fix

By default, forcing display: inline-block on all elements breaks standard CSS text-wrapping in Caption.Ninja, causing text to run off-screen in a single horizontal line.

To allow multi-line wrapping while keeping the red text, white outline, transparency, and pop animations, follow the updated steps below.

Step 1: Update the OBS Custom CSS

Double-click your Browser Source in OBS, clear out the Custom CSS field entirely, and paste this updated stylesheet:

/* 1. Reset background and allow text wrapping */
html, body, div, p, span, section, main, #output, #overlayMsgs {
  background-color: transparent !important;
  background: none !important;
  box-shadow: none !important;
  margin: 0 auto !important;
  overflow: visible !important;
  white-space: normal !important; /* Forces text to wrap onto new lines */
  word-wrap: break-word !important;
}

/* 2. Container sizing and alignment */
body, #output, #overlayMsgs {
  width: 90% !important; /* Constrains line width so text wraps before the screen edge */
  max-width: 1600px !important;
  text-align: center !important;
  position: absolute !important;
  bottom: 50px !important; /* Positions captions near the bottom center */
  left: 0 !important;
  right: 0 !important;
}

/* 3. Base text style: Red with White Border */
* {
  color: #FF0000 !important; /* Red text */
  font-family: 'Montserrat', 'Arial Black', sans-serif !important;
  font-weight: 900 !important;
  font-size: 46px !important;
  line-height: 1.3 !important;
  text-transform: uppercase !important;
  text-shadow: 
    -3px -3px 0 #FFFFFF,  
     3px -3px 0 #FFFFFF,
    -3px  3px 0 #FFFFFF,
     3px  3px 0 #FFFFFF,
    -4px  0px 0 #FFFFFF,
     4px  0px 0 #FFFFFF,
     0px -4px 0 #FFFFFF,
     0px  4px 0 #FFFFFF !important; /* Thick white outline */
}

/* 4. Pop-in animation for individual words ONLY */
span {
  display: inline !important; /* Keeps inline flow so wrapping works naturally */
  animation: redPop 0.15s ease-out forwards !important;
}

@keyframes redPop {
  0% {
    opacity: 0;
    transform: translateY(6px);
  }
  100% {
    opacity: 1;
    transform: translateY(0);
  }
}

Step 2: Add Word-Wrap Limits to Your URL

Caption.Ninja can automatically force a line break after a set number of words. Add &maxwords=6 to your URL so it breaks into 2 lines cleanly.

Update your Browser Source URL to this:

https://caption.ninja/overlay?room=qpxsL6y9Ho9SPCo0&maxlines=2&clear&interimmaxlines=2&maxwords=6

Step 3: Refresh the Source

  1. In the Browser Source properties, scroll down and click Refresh cache of current page.
  2. Make sure your Browser Source dimensions are set to Width: 1920 and Height: 1080.
  3. Click OK.

Verification: Speak a full sentence into your microphone—the text will wrap cleanly onto 2 lines near the bottom of the screen without running off the edge.

🎨 VDO.Ninja Animated Captions CSS

To create animated captions using VDO.Ninja (or Caption.Ninja), capture transcription data via speech-to-text parameters, send it to a browser overlay, and style the elements with Custom CSS inside OBS.

Step 1: Enable Transcription on Your Audio Source

If you are using VDO.Ninja to bring guest audio or your own webcam into OBS:

  1. Create your Push Link (the sender URL for your microphone/camera).
  2. Append &transcribe to the end of your Push URL: 
    https://vdo.ninja/?push=YOUR_STREAM_ID&transcribe

(This tells the browser to process speech-to-text continuously while streaming).

Step 2: Configure the Overlay Link in OBS

  1. Open your View Link (or Director Overlay link) where the video is received in OBS.
  2. Add &closedcaptions to the View URL to display live transcribed text over the video element: 
    https://vdo.ninja/?view=YOUR_STREAM_ID&closedcaptions
  3. Alternatively, if you want standalone caption overlays without the video feed, go to Caption.Ninja:
    • Launch your session and copy the generated Overlay URL.
    • Add this link into OBS as a Browser Source (Width: 1920, Height: 1080).

Step 3: Inject Dynamic CSS Animations in OBS

To replace standard scrolling text with word-by-word pop-ups, inject CSS into the OBS Browser Source.

  1. In OBS, double-click your VDO.Ninja / Caption.Ninja Browser Source.
  2. Scroll down to the Custom CSS text box.
  3. Replace the default CSS with the following snippet: 
    /* Hide default background */
body {
  background-color: rgba(0, 0, 0, 0);
  margin: 0px auto;
  overflow: hidden;
  font-family: 'Montserrat', 'Arial Black', sans-serif;
}

/* Style the text box */
#overlayMsgs, .caption-box {
  font-size: 42px;
  font-weight: 900;
  color: #ffffff;
  text-shadow: 3px 3px 0px #000000, -3px -3px 0px #000000, 3px -3px 0px #000000, -3px 3px 0px #000000;
  text-align: center;
  padding: 20px;
}

/* Animate every new word/span as it gets pushed */
#overlayMsgs span, span.word {
  display: inline-block;
  margin: 0 4px;
  animation: popIn 0.2s cubic-bezier(0.175, 0.885, 0.32, 1.275) forwards;
}

/* Keyframe for Kinetic Pop-In Effect */
@keyframes popIn {
  0% {
    opacity: 0;
    transform: scale(0.6) translateY(10px);
  }
  70% {
    transform: scale(1.15) translateY(-2px);
  }
  100% {
    opacity: 1;
    transform: scale(1) translateY(0);
  }
}

Verification Step

  1. Unmute your microphone on the VDO.Ninja push page and begin speaking.
  2. Observe your OBS Browser Source preview: as the browser finalizes incoming speech chunks, each phrase or line should scale up instantly with a kinetic bounce before resting into place.
